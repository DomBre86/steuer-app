# Steuer-App

Persönliche App zur Erfassung von Einnahmen, Ausgaben und Belegen für die gemeinsame Steuererklärung von Olga und Dominik.

- Erfassung auf dem iPhone und am PC (installierbare Web-App)
- Engagements als zentraler Kontext, dazu laufende und private Kosten
- Belege und Ordnerstruktur automatisch in OneDrive
- Jahresübersicht als Excel-Datei für die Steuerberatung

Eure Daten liegen ausschließlich im eigenen OneDrive, nicht in diesem Repository.
